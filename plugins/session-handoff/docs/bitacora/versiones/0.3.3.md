# 0.3.3 — La fase admite una nota después

- **Fecha**: 2026-11-19 · **Commit**: `c072ba9` · **Tipo**: fix
- **Visto en**: klinikae

## Síntoma

Una sesión escribió `Phase: external-wait (reintento commit ciclo 3, PID …)` mientras esperaba un commit en segundo
plano. La fase no coincidía exacta, se descartaba, y `Stop` bloqueaba tres veces hasta el tope en cada despertar.

## Cambio

- `progressFields` toma solo la primera palabra de `Phase`, como `Status` ya hacía con su motivo.

## Prueba

`hooks/handoff.test.ts`: `Phase: external-wait (…)` y `Phase: Verification — …` se reconocen;
`external-waiting` no.

## Lección

Tomar solo la palabra abrió otro hueco: la nota dejó de medirse (corregido en [0.4.3](0.4.3.md)).
