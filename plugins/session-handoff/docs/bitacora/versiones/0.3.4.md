# 0.3.4 — Una fase no válida se nombra al escribir `PROGRESS.md`

- **Fecha**: 2026-11-19 · **Commit**: `239f0f6` · **Tipo**: feat
- **Visto en**: klinikae

## Síntoma

Una sesión escribió `Phase: api-record tras merge de origin/dev (...)`. No es una fase: el plugin la descartaba en
silencio y `Stop` no podía reconocer `external-wait`.

## Cambio

- `PostToolUse` sobre `PROGRESS.md` devuelve `badPhaseText` junto al aviso de líneas largas.

## Prueba

`a PROGRESS.md written with a phase that is not one is named right away` (`hooks/register.test.ts`).

## Lección

Un valor que el plugin descarta debe avisarse en el momento en que se escribe, no al parar.
